# The-code-of-Project-The-Digital-Time-Trap-
This Code explores the" Attention Economy " to see how apps compete for our limited time. We are conducting an Observational Study to analyze if digital triggers, like notifications, successfully force users to stay online longer than they intended. To provide a unique insight, we introduce the "Zombie Ratio"—a metric that identifies users with high screen time but very low active engagement. Our goal is to statistically show the moment when helpful app usage turns into mindless scrolling.
